# Katkıda bulunma

1. Node.js 22.12+ ile `npm ci` çalıştırın; değişikliğiniz için ayrı bir dal açın.
2. Üretim anahtarları, gerçek müşteri yapılandırmaları ve içerik arşivleri eklemeyin. Testlerde sahte sağlayıcı kullanın; varsayılan testler ağa veya ücretli API'ye erişmemelidir.
3. Davranış değişikliğini ilgili test ve belgelerle birlikte hazırlayın. `npm run check` ve `npm run demo` çalıştırın; eklenen dosyalarda ve commit geçmişinde secret denetimi yapın.
4. Pull request açıklamasında değişen davranışı, doğrulamayı ve bilinen sınırları belirtin. Taslak/inceleme zorunluluğunu veya tekrar denetimini sessizce gevşetmeyin.

Katkılar bu deponun MIT lisansı altında sunulur. Güvenlik bildirimleri için [SECURITY.md](SECURITY.md) yönergelerini izleyin.
