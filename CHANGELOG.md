# Changelog

This file describes the scope of source versions. Until a GitHub Release and version tag are published separately, the `main` branch represents the current development state.

## 0.1.0 — 2026-10-21

- Configurable brand context, topic areas and question angles, with English as the default locale.
- Gemini-powered keyword proposals and structured article drafts.
- Keyword and title/excerpt similarity checks, with rejection of invalid responses.
- Mandatory draft status, editorial review reasons and safe error codes.
- Project-scoped local history and a concurrent-run file lock.
- Markdown and generic Payload export helpers, plus an authenticated POST handler.
- Offline demo, tests, English usage and GitHub guides, contribution templates and additional Turkish documentation.
- Standalone source repository without real credentials or customer data, licensed under MIT.

Live API access, CMS publication and distributed deployment are outside this version's verification scope.
